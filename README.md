# Tableau Sales Dashboard

This repository contains a sample dataset and instructions to build an interactive sales dashboard in Tableau. The dataset includes daily orders with regional, category, sales, and profit information.

## Dataset

- `tableau_sales.csv` – sample sales dataset with daily transactions, including order date, region, category, sales and profit.

## Visualization

- `sales_by_region.png` – bar chart summarizing total sales by region.

## Description

The provided dataset can be imported into Tableau to build interactive dashboards exploring sales trends by region, category and time.  The included bar chart offers a quick snapshot of regional sales differences.  From here, you can create additional views – such as profit over time or top categories – and combine them into a dashboard for deeper insights.
